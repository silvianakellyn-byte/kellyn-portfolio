AI 视频创作 · 提示词工程 · 内容设计

## 内容

- `index.html`：作品集网页，在 GitHub Pages 上可以直接播放视频
- `videos/`：视频作品（已压缩），网页分为个人作品、PixVerse 工作作品和比赛主题创作三个板块
- `posters/`：视频封面
- `skill/ai-video-clip-director/`：原创 AI 视频分镜与提示词 Skill，可用于 Claude、Codex 等 Agent

## 关于 AI Video Clip Director

这个 Skill 把创意或剧本拆成可以逐段生成的短镜头，再通过剪辑组合成片。适用于动作短片、角色 MV、TVC 和 showcase 的制作与返修，目标模型包括 Seedance、MiniMax H3 等。内容来自本人在 AI 视频制作中的实践总结。

安装方法：把 `skill/ai-video-clip-director` 文件夹复制到所用 Agent 的 skills 目录。
