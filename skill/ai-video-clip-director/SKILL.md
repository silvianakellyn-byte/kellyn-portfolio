# AI Video Clip Director

作者：周凯琳 Kellyn。方法来自本人在 AI 视频 showcase、动作短片和角色 MV 制作中的实践总结。

## 核心理念

AI 视频的节奏感主要来自剪辑，而不是单条长镜头。一个情绪段落拆成 3–4 条短镜头分别生成，每条只做一件事，再在剪辑里拼接。这样单条更稳定，返修时只需重做出问题的那一条。

三条基本判断：

1. **每条只做一个主要动作**：动作越多，越容易变形、跳帧或动作做不完。
2. **可用素材按 2–3 秒计划**：即使生成 5–15 秒，也只指望其中最好的 2–3 秒进成片。
3. **文字、UI 和 HUD 放到后期做**：模型生成文字很不稳定，画面里只留干净素材。

## 工作流程

### 第 1 步：锁定需求

开始写之前先确认以下几项。用户没说的按默认值补全，并在回复里写一行说明采用了哪些假设：

| 项目 | 默认值 |
|---|---|
| 目标模型 | 按用户指定；未指定时问一句 |
| 成片时长 | 15–30 秒 |
| 画幅 | 横屏叙事用 16:9，社媒竖屏用 9:16 |
| 单条生成时长 | 动作镜头 5 秒，环境或氛围镜头 5–10 秒 |
| 原创边界 | 是否借鉴了某个 IP、真实事件或真人（见"原创与伦理边界"） |
| 声音 | 由模型生成音频，还是后期配乐 |

只追问会改变整体方案的缺口，比如主角是谁、两个角色之间的空间关系。其他缺项先合理补全。

### 第 2 步：节拍表

先用一句话写出情绪走向，再拆成 4–6 个节拍，例如：钩子 → 建立 → 升级 → 高潮 → 收尾。每个节拍标注：

- 大致时长
- 观众应感受到什么
- 对应几条镜头：动作段落 3–4 条快切，情绪段落 1–2 条稳定镜头

### 第 3 步：镜头清单

每条镜头用一行概括，方便用户先看整体节奏：

`编号 | 节拍 | 景别/机位 | 单一主要动作 | 入画方式 → 出画方式 | 可用秒数`

检查清单：

- 连续两条镜头不要重复相同的景别和运镜。
- 快镜后面接一个稳镜，给观众喘息的空间。
- 每条镜头的结束状态，要能接上下一条的开头，比如动作方向、视线、遮挡。
- 给高潮留一个冲击帧：画面最有力量的一瞬间。

### 第 4 步：逐条写提示词

提示词用英文写（用户另有要求或目标模型更适合中文时除外）。每条按以下顺序组织：

1. **主体与锁定项**：角色外观、服装、关键道具，每条都要完整重复，不写"同上"。
2. **动作从中段开始**：不写起跑、准备、蓄力，直接进入动作最有张力的那一刻。
3. **速度语言**：用 explosive、whip-fast、snap、instant、in a blur of motion 这类词，比 fast 更有效。
4. **冲击帧**：明确写出接触、落地或爆发的一瞬，例如 impact frame as the heel lands。
5. **镜头**：起始构图、运动方向、结束构图。动作已经很激烈时，镜头保持简单。
6. **环境次级运动**：尘土、碎屑、布料、光线变化，用来增加真实感。
7. **质量锁**：只写和这条镜头有关的风险，例如 two distinct bodies never merging, no limb smear, face stays consistent。
8. **风格与光线**：整组镜头保持一致的色调和质感描述。

长度控制：单条提示词不超过 5,000 字符。描述要具体，但去掉重复的形容词。

### 第 5 步：后期层清单

列出需要在剪辑软件里加的内容：标题、字幕、HUD、倒计时、选择框、Logo、转场特效、音效点。每项写清楚出现在第几条镜头、第几秒。

### 第 6 步：交付

回复结构：

1. 一行假设说明
2. 节拍表
3. 镜头清单表
4. 每条镜头一个独立代码块的提示词，方便直接复制
5. 后期层清单
6. 生成时重点观察的 2–3 个风险点

只说明提示词已按清单检查过，不保证生成效果；效果要看实际成片。

## 模型经验

### 速度与稳定的取舍

速度越快，越容易出现肢体融合、手脚拖影、脸部变形，两个身体快速碰撞时尤其明显。处理方法：

- 碰撞或打斗拆成"出手"和"命中"两条镜头，不在一条里完成。
- 加入针对性的质量锁。
- 实在不稳时，降低一档速度描述，靠剪辑补节奏。

### 否定描述的风险

部分模型会把否定句里的东西画出来，比如写 no mask 反而出现面具。尽量改成正面描述：

| 避免 | 改为 |
|---|---|
| no mask | bare face fully visible |
| no text on screen | clean frame, plain unmarked surfaces |
| not wearing a cape | fitted hoodie ending at the waist |

确实需要排除时，否定句放在最后，并且只写一次。

### 参考图里的标注会漏进成片

如果参考图上画了箭头、圈注或文字说明，模型可能把它们当成画面内容。上传前先清理标注；需要保留时，在提示词里说明这些标注只是运镜示意，不出现在画面中。

### 动作参考的用法

有白模或 3D 动作预演时，用它锁定动作和机位，再用提示词补充质感、光线和角色外观。提示词要写明"动作沿用参考"，避免模型重新编排动作。

## 原创与伦理边界

### 借鉴已有 IP

可以借鉴的是动作词汇和类型手法，比如蹲伏、扑跃、翻越、贴墙跑。不能出现的是该 IP 的标志性服装、面具、配色、道具、名字和 Logo。写角色时给出一套完整的原创外观，并在每条提示词里重复。

### 改编真实事件

只借用事件的结构或机制，比如地质过程、救援流程。不使用真实地名、伤亡数字、遇难者故事和真人形象，世界观和角色都做虚构化处理。

### 真人与品牌

不生成可识别的真人肖像。品牌元素只在用户有权使用时加入，并优先放到后期合成。

## 返修

先判断问题属于哪一类，再只改受影响的镜头：

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 人物几乎不动 | 动作写得太抽象，或者只写了氛围 | 写一个具体动作，并写出起点和落点 |
| 动作做到一半就结束 | 单条塞了太多事件 | 拆成两条，或删掉次要动作 |
| 肢体融合、拖影 | 速度过高、身体接触复杂 | 拆成出手和命中两条，加质量锁，降一档速度 |
| 角色前后不一致 | 锁定项没有每条重复 | 补全外观描述，统一用词 |
| 出现不该有的元素 | 否定描述或参考图标注泄漏 | 改成正面描述，清理参考图 |
| 画面文字乱码 | 让模型直接生成了文字 | 删掉文字要求，改到后期加 |
| 剪起来不顺 | 前后镜头方向、景别重复或接不上 | 调整出画和入画方向，插一个稳镜或细节镜 |

有视频时先看出问题的时间段再判断。只有文字反馈时，把原因写成"待验证的推测"。修改后交付完整的新版提示词，不只给补丁段落。
